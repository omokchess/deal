    행동 순서
      기어 0/4

      유물 · 인챈트 0/2

      클래스 & 스킬

      베이스 클래스는 상위 슈퍼 클래스의 스킬을 그대로 따릅니다.

      스킬 수치

      Base × (1 + Σ(스탯 ÷ 계수)) — 예) 근력 100, 계수 75 → ×2.333. 계수 분모가 트렐로에 없는 스킬은 0으로 들어오니 직접 채우세요.

      내 스탯
      특성 · 상황
      대미지 필드 · 직접 입력

      Multi는 합연산입니다. +10% 5개는 1.1⁵(1.61)이 아니라 1.50.

      대상 방어 필드 · 직접 입력

      Reduc은 퍼센트가 아닙니다. 100 → 50% 감소, 300 → 75% 감소. 음수면 증폭이며 최대 2배에서 멈춥니다.

      소울 트리 0p

      소울 포인트는 환생 시 지급됩니다 — 베이스 클래스 20 / 슈퍼 클래스 50 / 첫 보스 50 / 유물 장착 75 / 언약 10레벨 50 / 20레벨 75. 트렐로에 적힌 갈래별 합계(공격 6,150 · 방어 4,275 · 유틸 3,975)는 나열된 노드 비용을 더한 값과 맞지 않습니다. 여기 표시되는 합계는 노드 비용을 실제로 더한 값입니다.

      마스터리 0/35

      한 슬롯당 마스터리 포인트는 최대 35개라 세 갈래 중 두 갈래까지만 채울 수 있습니다 (가운데 5코스트 노드를 건너뛰면 좌·우 둘 다 가능). 일반 노드는 아래로 갈수록 스탯 제공량이 늘어나는데 트렐로에 정확한 수치가 없어, 노드당 평균 스탯을 직접 조절하게 해뒀습니다 (기본 1.0). 돌파 능력·강화 돌파는 「빌드」 탭의 클래스 패시브 목록에서 켜세요.

      전투 설정

      도트는 대상 최대 체력 기준으로 턴마다 자동 적용됩니다. 화상 0.7%/스택, 유령 불꽃 3.85%, 출혈 3%, 중독 스택당 1. 보스는 이 값의 10%만 받습니다.

      파티

      파티원의 지원 효과는 내 Multi에 합산되고, 기여 피해량은 시뮬레이션 총합에 더해집니다. 아래 「버프 · 디버프」에서 같은 항목을 또 켜면 이중 계산되니 하나만 쓰세요. 파티가 있으면 시비가 6단계까지 올라 적이 강해집니다.

      행동 시뮬레이션
      시퀀스 총 피해량—

      턴마다 자동 반영: Fleet(1턴차), Momentum(연속 공격 턴, 최대 3), 배인글로리우스 로켓(턴차별 감소), 코아귤레이트 핑거 네일(턴당 누적), 야툴 워레스 과열(5턴당 1스택), 명상 다음 턴 보정. 쿨타임과 에너지가 모자라면 ⚠ 로 표시되고 그 턴은 0으로 칩니다. 오른쪽 상세 패널은 선택한 턴 기준입니다.

      빌드 역산

      지금 고른 스킬과 대상 방어 수치를 기준으로, 스탯 배분 → 기어 4칸 → 특성 슬롯 → 조건부 버프 순서로 탐색해 목표치에 닿는 최소 구성을 찾습니다. 켜져 있는 항목은 무시하고 처음부터 다시 짭니다.
